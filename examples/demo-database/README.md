# Ink Browser Demo Database

This folder contains a public sample database for the local Ink Browser interface.

- Database directory: `database/`
- Demo signing key: `demo-admin.key`
- Tables: `orders`, `inventory`, `customers`, and `_ink_access`
- Records: 11, including one correction record
- Access grants: the demo key has administrative, reader, and writer roles scoped to `*` inside this sample database

The private key is intentionally unencrypted and exists only for this disposable sample database. It is not suitable for any other database or real data.
